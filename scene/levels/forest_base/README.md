# Основа лесного уровня

Откройте `forest_base.tscn` и выберите `EnvironmentGrid`.
Палитра MeshLibrary заполняется tool-скриптом при открытии сцены: две сосны и три секции забора из существующих GLB.

- Размер клетки — 2 × 2 × 2 м, основание объектов на Y=0.
- Расставляйте модели стандартными инструментами GridMap. Поворот на 90° позволяет строить забор в разных направлениях.
- Каждая секция забора масштабируется до ширины одной клетки; сосны — до высоты 5 м.
- Коллизии входят в библиотеку: цилиндр ствола и прямоугольная секция забора. Листва не блокирует движение.
- `Tree Height` и `Rebuild Library` в инспекторе GridMap позволяют изменить высоту деревьев и пересобрать библиотеку. Существующие клетки сохраняются по идентификаторам элементов.
- Сохраните сцену после генерации: библиотека встроена в сцену и сохраняется вместе с ней.

Земля 60 × 60 м, свет, игрок, изометрическая камера и HUD уже добавлены. GridMap изначально пустой для свободной планировки.
Другие сцены и стартовая сцена проекта не изменяются. Навигационная сетка для врагов пока не добавлена.
