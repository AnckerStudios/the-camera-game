# Инвентарь

Q открывает и закрывает инвентарь. Игра останавливается, камера приближает персонажа справа.
Слева — освещённая 3D-карусель: выбранная модель крупнее двух соседних. Одновременно отображаются максимум три модели.
A/D или действия move_left/move_right переключают предметы. E открывает нижний ряд действий.
В контекстном меню A/D выбирают действие, E подтверждает. Можно нажимать кнопки мышью.

- Надеть / применить: экипирует оружие или фильтр, лечит либо передаёт патроны совместимому оружию.
- Выбросить: возвращает весь выбранный стек в мир. Его можно подобрать обратно; у оружия сохраняются патроны и состояние.
- Отмена: закрывает контекстное меню.
- Снять: заменяет «Надеть», если предмет уже экипирован.

Два оружия и фильтр отображаются справа. Нажатие на кнопку оружия при открытом контекстном меню выбирает слот, куда оно будет надето. По умолчанию выбирается свободный слот, иначе первый.

Модели берутся из действующего оружия, model_scene или weapon_scene. При отсутствии модели используется 3D-заглушка соответствующего типа.

## Создание предмета

В PickupItem назначьте inventory_item — ресурс InventoryItem; quantity задаёт количество.
- WEAPON: weapon_scene с корнем Weapon. Размер стека — 1.
- AMMO: weapon_id совпадает с именем оружия, например WeaponRevolver; quantity — число патронов.
- MEDICINE: healing — здоровье за одну единицу.
- FILTER: filter_mode — режим фильтра. Размер стека — 1.

Общие поля: id, display_name, description, icon, model_scene, max_stack.
Без inventory_item тестовый предмет использует свои данные и тип MEDICINE.
Если инвентарь заполнен, предмет остаётся в мире. После успешного подбора сохраняется прежнее окно осмотра.
Данные принадлежат текущему персонажу; сохранения между запусками игры нет.
